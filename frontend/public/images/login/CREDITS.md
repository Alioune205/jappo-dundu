# Photo de la page de connexion

| Fichier | Sujet | Utilisation |
|---|---|---|
| `equipe-ecran` | Une médecin et deux infirmiers devant un écran tactile Jappo Dundu | Volet photo de la connexion |

Image fournie par l'équipe du projet. Original (1376 × 768, PNG) dans
`design-sources/login/equipe-ecran-jappo.png` ; versions web produites avec :

```sh
ffmpeg -i equipe-ecran-jappo.png -c:v libwebp -quality 80 equipe-ecran.webp
ffmpeg -i equipe-ecran-jappo.png -q:v 3 equipe-ecran.jpg
```
